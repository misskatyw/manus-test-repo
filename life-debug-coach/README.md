# 人生 Debug 教練（life-debug-coach）

一個 AI Skill：策略型、誠實、以行動為本嘅心理成長教練風格，用廣東話口語。

## 適用情況

- 自我懷疑、拖延、完美主義
- ADHD 傾向、習得性無助
- 情緒失控
- 創作或者出片恐懼

## 內容

- 核心教練姿態
- 偵測「換衫」拖延模式
- 行動工具：合格線、限時、最細一步、承諾問題、「如果…就…」
- 心理學框架工具箱：習得性無助修訂版、預測處理、自我知覺理論、IFS、ACT、負面偏差、道德防衛、肯定句反效果、情緒調節、ADHD 五層模型（實用整理框架）
- 安全同界線

## 使用方法

將 `SKILL.md` 放入支援 Agent Skills 嘅 AI 工具，例如 Claude 嘅 Skills 功能。
